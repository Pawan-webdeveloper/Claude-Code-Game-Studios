# Bug Report

## Summary
**Title**: Greninja cannot be summoned on land
**ID**: BUG-0003
**Severity**: S3-Medium
**Priority**: P1-Fix this sprint
**Status**: Open
**Reported**: 2026-11-08
**Reporter**: Pawan

## Classification
- **Category**: Gameplay
- **System**: Ride switching rules (src/rides/rideLogic.ts)
- **Frequency**: Always
- **Regression**: No (design change)

## Environment
- **Build**: uncommitted working tree on 05ad7c8 (first playable, 2026-11-08)
- **Platform**: Browser (Chrome, desktop + mobile emulation), Three.js 0.170
- **Scene/Level**: Trainer's Atlas open world
- **Game State**: any

## Reproduction Steps
1. Land on ground as Gengar.
2. Press 3 (or the Greninja button).

**Expected Result**: Greninja is summoned and can run on land as well as water.
**Actual Result**: The request maps to Gengar because the surface is land; Greninja is also auto-swapped back to Gengar on reaching land.

## Technical Context
- **Likely affected files**: src/rides/rideLogic.ts (manualSwitch, autoSwitch), src/rides/rides.ts (GreninjaRide.floor), tests/unit/rides/rideLogic.test.ts
- **Possible root cause**: manualSwitch/autoSwitch treat Greninja as water-only.

## Notes
New rule: Greninja is amphibious (land + water). Gengar stays land-only and becomes Greninja when it enters water.

## Fix Applied (2026-11-08, awaiting `/bug-report verify BUG-0003`)
- Greninja is amphibious: summonable anywhere, runs on land (floor = max(terrain, water)), never auto-swapped back to Gengar (src/rides/rideLogic.ts, src/rides/rides.ts). Unit tests: tests/unit/rides/rideLogic.test.ts (37 passing). Verified in browser: summoned on land.
